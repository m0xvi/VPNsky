# VPNsky — корпоративный VPN-клиент с удалённым управлением

Закрытый (private) проект: кроссплатформенный VPN-клиент для сотрудников + админское
приложение (Android/Windows) + серверный центр управления. Строится на открытых
компонентах, но собственный код и UI — проприетарные.

Состояние: **этап 0 — проектирование**. Кода приложения ещё нет.

## Кратко о выборе

- **Ядро клиента — Xray-core** (MPL-2.0, file-level copyleft): закрытый UI можно,
  а самодостаточность ядра (VLESS+REALITY, XHTTP, Hysteria2-исходящий, TUN для
  Windows/macOS/Linux/Android/iOS, WFP-блокировка утечек) позволяет обойтись без второго движка.
- **Не берём sing-box / Karing / Hiddify как основу** — GPLv3 (+ доп. условия у Hiddify):
  несовместимо с закрытым продуктом.
- **Транспорты:** VLESS+REALITY (TCP/443) → VLESS+XHTTP (fallback) → Hysteria2 (UDP/QUIC).
  Автопереключение делает клиент, а не сотрудник.
- **UI — Flutter** (Windows + Android + будущий iOS из одной кодовой базы),
  админские экраны — отдельная сборочная конфигурация (flavor), не та же сборка, что у сотрудников.
- **Control plane — свой сервис на Go** + индивидуальные учётные данные на устройство
  через Xray API и HTTP-авторизацию Hysteria2. Никаких панелей 3x-ui в проде.

Подробности, оговорки и то, что ещё не проверено, — в документах выше.

## Статус

Этап 0: проектирование. Data plane будет разворачиваться на **отдельном тестовом VPS**;
текущий сервер с 41 клиентом не трогаем. Так как нужен доступ к зарубежным сервисам,
параллельно с разработкой имеет смысл подать заявление в ЦМУ ССОП на включение IP exit-узла
в «белый список» — детали и шаблон в [`docs/РЕШЕНИЯ.md`](docs/РЕШЕНИЯ.md).
