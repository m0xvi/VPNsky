# VPNsky — корпоративный VPN на готовых open-source компонентах

Задача: 50+ сотрудников, Windows/Android/iPhone, управление из админки, минимум действий
для сотрудника. Решение — **не писать свой клиент, а развернуть готовый стек**:
Remnawave (панель + ноды на Xray-core) + готовая страница подписки + готовые клиенты
(Happ / Hiddify / v2rayTun).

Состояние: **выбор сделан, развёртывания ещё не было.** Кода приложения нет и не требуется.

## Коротко

- **Панель:** Remnawave Panel 3.4.8 (AGPL-3.0) — пользователи, ноды, подписки, лимит устройств, Telegram-уведомления.
- **Нода:** Remnawave Node 3.4.4 с Xray-core — VLESS+REALITY (TCP/443), VLESS+XHTTP (TCP/8443), Hysteria2 (UDP/443).
- **Сотрудник:** ссылка → страница подписки определяет ОС → установка приложения → кнопка «Подключить» (deeplink `happ://add/...`) → готово. При смене конфигурации ничего делать не нужно.
- **Админ:** веб-панель; на телефон ставится как PWA (отдельное приложение не нужно).
- **Серверы:** панель — отдельно (2–4 GB RAM), нода — за рубежом (1–2 GB). Обе Ubuntu 22.04+, Docker.

Открытый код здесь ничему не мешает: AGPL при использовании внутри компании обязательств
по раскрытию вашего кода не создаёт — вы просто эксплуатируете программу.
