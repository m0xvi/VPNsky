# Установка сервера NSky

Домен панели: `oijas.rknmrz.xyz` → `147.45.152.7` (проверено, DNS работает).
Сервер чистый, Ubuntu Server. Ниже — порядок действий.

---

## Шаг 0. Точка восстановления (сделать ДО установки)

Вы правы, что начинаете с этого. На Ubuntu есть три уровня отката — от лучшего к худшему.

### Уровень 1 — снапшот диска (лучший)

Если хостинг умеет снапшоты (почти все VPS умеют):

1. Панель хостинга → ваш сервер → **Snapshots** / **Backups** → **Create snapshot**.
2. Дождаться статуса «готов».

Откат — восстановление снапшота целиком: возвращается и система, и данные, и Docker.
**Сделайте это сейчас, пока система чистая.** Установщик тоже делает свой снимок,
но снапшот хостинга надёжнее: он вне диска.

### Уровень 2 — снимок конфигурации (делает установщик автоматически)

Скрипт `deploy/install.sh` перед изменениями сохраняет в `/opt/nsky-backups/`:

- `*.tar.gz` — конфиги firewall, sshd, systemd, уже установленные файлы NSky;
- `*.packages.txt` — список пакетов (видно, что появилось);
- `КАК_ОТКАТИТЬ.txt` — инструкция на трёх уровнях.

### Уровень 3 — ручной снимок через tar (если снапшотов нет)

```bash
sudo mkdir -p /root/backups
sudo tar -czf /root/backups/before-nsky-$(date +%F).tar.gz \
  --absolute-names /etc /opt 2>/dev/null
```

Не пугайтесь размера: конфиги занимают десятки мегабайт, базы данных ещё нет.

## Шаг 3. Установка одной командой

Скопируйте на сервер скрипт установки (он лежит в репозитории):

```bash
mkdir -p /opt/nsky-src && cd /opt/nsky-src
curl -fsSL -o install.sh https://raw.githubusercontent.com/m0xvi/VPNsky/main/deploy/install.sh
```

Запуск:

```bash
bash install.sh oijas.rknmrz.xyz admin@rknmrz.xyz
```

Что произойдёт (5–10 минут):

1. Снимок конфигурации в `/opt/nsky-backups/`.
2. Установка Docker, если его нет; ограничение логов, чтобы не забить диск.
3. Firewall: открыты 22, 80, 443/tcp, 8443/tcp, 443/udp, 2222/tcp. Остальное закрыто.
4. Генерация всех паролей и секретов — вручную ничего придумывать не нужно.
5. Запуск панели Remnawave (панель + Postgres + Valkey).
6. Caddy: получение сертификата Let's Encrypt для `oijas.rknmrz.xyz`.

## Шаг 4. Первый вход в панель

Откройте **https://oijas.rknmrz.xyz** — сертификат уже выпущен.

Панель предложит создать администратора. Создайте первого (вы), второго добавьте
там же: **Users → Create user → роль ADMIN**.

## Шаг 5. Подключение ноды (сервер, через который ходит трафик)

1. В панели: **Nodes → Create Node**. Скопируйте `SECRET_KEY` (показывается один раз).
2. На сервере, короткими блоками:

```bash
mkdir -p /opt/nsky/node && cd /opt/nsky/node
```
```bash
curl -fsSL -o docker-compose.yml https://raw.githubusercontent.com/m0xvi/VPNsky/main/deploy/node/docker-compose.yml
```
```bash
SECRET_KEY='вставьте_сюда_ключ' docker compose up -d
```

3. В панели нода должна загореться зелёным (до 30 секунд).

## Шаг 6. Профиль Xray (протоколы)

В панели: **Config Profiles → Create**.

Протоколы, которые поддерживает наш профиль:

| Протокол | Порт | Зачем |
|---|---|---|
| VLESS + REALITY | 443/tcp | основной, маскируется под обычный HTTPS-сайт |
| VLESS + XHTTP | 8443/tcp | резерв, если REALITY начнут фильтровать |
| Hysteria2 | 443/udp | быстрый на плохих сетях, для мобильных |

Файл профиля — `deploy/xray/profile-reality-xhttp-hysteria2.json` в репозитории.
Перед заливкой замените плейсхолдеры (в панели есть генератор ключей x25519:
**Settings → Tools**).

## Шаг 7. Первая подписка для проверки

1. **Users → Create user**, срок действия — например 30 дней, лимит трафика — 100 ГБ.
2. Откройте пользователя → скопируйте **Subscription URL**.
3. Сформируйте ссылку для клиента:

```
nsky://install-config?url=<Subscription URL>
```

Её достаточно отправить сотруднику — клиент сам подхватит настройки.
Или сделайте QR: в панели у пользователя есть кнопка QR.

## Шаг 8. Проверка на готовых клиентах (до своей сборки)

Вы просили проверить подключение до того, как наш клиент будет готов. Это правильно.

**Windows:** Happ (`https://github.com/Happ-proxy/happ-desktop/releases`) — импорт
подписки по ссылке.
**Android:** Happ из Google Play / со страницы релизов; либо v2rayNG — вставить
Subscription URL.
**iOS:** Streisand, Shadowrocket (платный).

Критерий успеха: в клиенте видно 3 сервера/протокола, при включении открывается
`https://ifconfig.me` и показывает **IP сервера**, а не домашний.

## Что проверить после установки

```bash
# панель жива
curl -fsS http://127.0.0.1:3001/health
```
```bash
# контейнеры запущены
docker ps --format 'table {{.Names}}\t{{.Status}}'
```
```bash
# firewall
ufw status numbered
```

Порты, которые **не должны** быть видны снаружи: `3000`, `3001`, `6767`.
Проверка с другого компьютера: `telnet 147.45.152.7 3000` должен не подключаться.

## Если что-то пошло не так

| Симптом | Куда смотреть |
|---|---|
| Панель не открывается | `docker logs remnawave`, `systemctl status caddy` |
| Сертификат не выпустился | домен должен указывать на IP, порт 80 открыт: `ufw status` |
| Нода не загорается зелёным | `docker logs remnanode`, порт 2222 достижим с панели |
| Клиент не подключается | профиль Xray импортирован? нода включена? порт открыт? |
| Всё сломалось | `/opt/nsky-backups/КАК_ОТКАТИТЬ.txt` или снапшот хостинга |

## Откат целиком

```bash
cd /opt/nsky/panel && docker compose down -v
```
```
systemctl stop caddy && apt-get remove --purge -y caddy
```
```
rm -rf /opt/nsky
```

Снапшот хостинга — на случай, если и это не помогло.
