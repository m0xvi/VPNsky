## Замечание об источниках

Строка в README о поддержке платформы или протокола — отправная точка, а не проверка конкретного устройства и сервера. GitHub issues — сообщения отдельных участников, а не установленная причина текущей неисправности. Условия лицензий цитируются как текст авторов; юридические выводы и совместимость с магазинами нужно отдельно проверять.
