# Что сделать сейчас — 5 шагов

Только действия, по порядку. Не пропускайте и не меняйте порядок.
Каждый шаг — на своей машине. Команды вставлять **по одной строке**, Enter
после каждой; если в строке появился мусор — `Ctrl+C` и повторить.

---

## Шаг 1 — русский VPS (`msk-…`)

Одна команда:

```
iptables -t nat -A PREROUTING -p tcp --dport 443 -j DNAT --to-destination $(cat /opt/nsky-relay/nl-ip):8443
```

**Не перезагружайте этот VPS**, пока не дойдёте до шага 5: правило временное.

---

## Шаг 2 — нидерландский VPS (`ams-…`)

Две команды, по одной:

```
curl -fsSL -o /root/nsky-cascade-check.sh https://raw.githubusercontent.com/m0xvi/VPNsky/6fd030edb1285fe58fb5ce8cfea5abda045705f9/deploy/nsky-cascade-check.sh
bash /root/nsky-cascade-check.sh
```

Посмотрите на последнюю строку вывода. Должно быть **ошибок: 0**.

Если написало иначе — остановитесь и пришлите этот вывод мне.

---

## Шаг 3 — ваш ПК, браузер

1. Откройте `https://<домен>:8444`.
2. Появится форма регистрации — зарегистрируйте администратора заново
   (после сброса админ был удалён).
3. `Users` → строка тестового пользователя → **иконка ссылки** → скопируйте
   подписку. Это **новая** ссылка: старая после смены секрета не работает.

---

## Шаг 4 — телефон, при включённом Wi-Fi

1. В Happ **удалите** старую подписку.
2. Нажмите `+` и добавьте ссылку из шага 3.
3. Должно появиться 6 серверов.

---

## Шаг 5 — телефон, только LTE Билайн

1. Wi-Fi **выключить**.
2. В Happ вручную выбрать **`NSky REALITY (RU)`** (строка должна подсветиться).
3. Нажать «Подключить».
4. Открыть:

```
https://1.1.1.1/cdn-cgi/trace
```

Увидели нидерландский IP — готово.

---
