## Одно действие — телефон (LTE, Wi-Fi выключен)

В Happ выбрать **вручную** `NSky Hysteria2 (RU)` — это **UDP/443 (QUIC)**,
другой стек, без REALITY и без TLS-сертификата прикрытия.

1. Happ → Отключить.
2. Выбрать `NSky Hysteria2 (RU)` → **Подключить**.
3. Дождаться «ПОДКЛЮЧЕН» и открыть `https://example.com`.
4. Если открылось — проверить внешний IP: должен быть нидерландский.

**Почему именно он:** все прошлые замеры tcpdump имели фильтр `tcp`, поэтому
UDP/443 в них **физически не попадал**. Фраза «с остальными по нулям»
относилась только к TCP‑протоколам. А на релее `udp dpt:443` уже показывал
`36 пакетов / 46 КБ` — это настоящий QUIC‑обмен, не пустые пробы.

## Запасной шаг, если Hysteria2 не открыл страницу

**На нидерландском VPS**, одной строкой (только чтение). В этот раз замер
слушает UDP, а не TCP:

```
curl -fsSL -o /root/nsky-live-probe.sh https://raw.githubusercontent.com/m0xvi/VPNsky/b8a8c54c2ba37eeba81a4eed3c19afc60b74fb9d/deploy/nsky-live-probe.sh && bash /root/nsky-live-probe.sh --udp
```

Когда напишет «выберите Hysteria2 (RU)» — нажать «Подключить» на телефоне.
Вердикты: `U2` — QUIC идёт в обе стороны, `U1` — нода молчит, `U0` — выбран
не тот сервер.
