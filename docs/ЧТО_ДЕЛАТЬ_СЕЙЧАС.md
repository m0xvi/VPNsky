## Осталось 3 действия

### 1. Телефон — подключить и не выключать

1. Wi-Fi **выключить**, LTE Билайн **включить**.
2. Happ → вручную выбрать **`NSky REALITY (RU)`** (строка подсвечена).
3. Нажать «Подключить» и **дождаться** надписи «ПОДКЛЮЧЕН» с таймером.
4. **Не нажимать кнопку питания второй раз** и не выходить из Happ.

Если Happ сам сразу пишет «Остановка служб» и не держит «ПОДКЛЮЧЕН» — это и
есть главный факт, который нужно прислать.

### 2. Телефон — открыть сайт, только когда написано «ПОДКЛЮЧЕН»

```
https://1.1.1.1/cdn-cgi/trace
```

Если пусто, попробовать:

```
https://example.com
```

Открылась страница или показала нидерландский IP — **готово**.

### 3. Если обе страницы пустые — русский VPS, одна команда

```
iptables -t nat -L PREROUTING -nv | grep 'tcp dpt:443'
```

Записать число пакетов **до** попытки подключения на телефоне, потом нажать
«Подключить» в Happ, подержать 10 секунд и повторить ту же команду.

- число **выросло** → пакеты до релея доходят, смотреть уже NL-ноду;
- стоит **на нуле** → телефон не доходит до релея или выбран не тот сервер.

> Если в `PREROUTING` окажется две одинаковые строки про `tcp dpt:443` — это
> не страшно, первая сработает, вторая просто не используется. Убирать не надо.
