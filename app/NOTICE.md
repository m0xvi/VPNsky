под какой лицензией и что изменено. Это требование GPLv3, и заодно единственный способ
не потерять совместимость с законом при закрытых внутренних сборках.

## Что изменено в этой версии

1. **Брендинг**: имя приложения `VPNsky`, пакет `ru.vpnsky.client`, служба
   `VPNskyHelperService`, идентификаторы Android/macOS, имена сокетов и pipe.
2. **Навигация**: из главного меню убраны разделы для разработчика и диагностики;
   они перенесены в «Ещё» и открываются только по запросу поддержки.
   Оставлены: подключение, профили, выбор сервера, настройки.
3. **Тексты для сотрудника**: добавлен `lib/common/vpnsky_texts.dart` с формулировками
   статусов и ошибок, ориентированными на не-технического пользователя.
4. **Сборка**: собственный workflow `.github/workflows/build-vpnsky.yml` (Windows + Android),
   потому что upstream-workflow отключает сборку в приватных репозиториях.
5. **Удалено**: рекламные блоки и ссылки на сторонние VPN-сервисы из README.

Удаление или изменение функциональности не отменяет GPL: исходники этой версии должны быть
доступны получателям бинарников. Внутреннее использование внутри компании получателями
не является, но при передаче сборки сотруднику исходники должны быть ему доступны.
Практика: репозиторий с этим кодом открывается (делается публичным) либо каждому
получателю передаётся архив исходников вместе с бинарником.

## Обновления от upstream

Апстрим выпускает релизы часто. Обновление делается так:

```bash
git remote add upstream https://github.com/chen08209/FlClash.git
git fetch upstream --tags
git merge upstream/vX.Y.Z     # разрешить конфликты в перечисленных выше файлах
```

Все наши правки сосредоточены в небольшом числе файлов (см. список выше) — конфликты
предсказуемы.
